Introducción

El sistema operativo (SO) es el software que administra los recursos de una computadora (procesador, memoria, almacenamiento y dispositivos) y ofrece a usuarios y programas una interfaz sencilla para usarlos. Sin él, cada aplicación tendría que controlar el hardware directamente.

Esta página reúne los temas del curso: desde los orígenes de la tecnología y la historia de los SO hasta procesos, hilos y el algoritmo del banquero, cerrando con una comparación de sistemas operativos para servidores.

4Hardware y software de la computadora

⚙️ Hardware

Parte física: CPU, RAM, almacenamiento (HDD/SSD), placa madre y dispositivos de entrada y salida.

💾 Software

De sistema: SO, drivers, firmware (UEFI).
De aplicación: navegadores, juegos, ofimática.
De desarrollo: compiladores y editores.

El SO es el intermediario: las aplicaciones piden servicios mediante llamadas al sistema y el SO habla con el hardware.

7Algoritmo del banquero

Propuesto por Edsger Dijkstra para evitar interbloqueos (deadlocks). Antes de conceder un recurso, comprueba que el estado siga siendo seguro: que exista al menos una secuencia en la que todos los procesos puedan terminar, como un banco que solo presta si puede garantizar que todos sus clientes completen sus operaciones.

Estructuras: Available, Max, Allocation y Need = Max − Allocation.

🎮 Simulador (Available inicial = 3 3 2)

Work = 3 3 2 · Secuencia: —

ProcesoAllocationMaxNeed

Pulsa el botón: en cada paso se busca un proceso con Need ≤ Work.

Algoritmo de seguridad: 1) Work = Available y Finish = false. 2) Buscar un i con Need[i] ≤ Work. 3) Work = Work + Allocation[i]; Finish[i] = true y repetir. 4) Si todos terminan, el estado es seguro.

Solicitud: se verifica Request ≤ Need y Request ≤ Available, se simula la asignación y se ejecuta el algoritmo de seguridad. Solo se concede si el estado resultante es seguro.

8Hilos

Un hilo (thread) es la unidad básica de ejecución dentro de un proceso. Comparten código, datos y archivos, pero cada uno tiene su propio contador de programa, registros y pila.

9Procesos

Un proceso es un programa en ejecución, con código, datos, heap, pila y estado del procesador. El SO lo representa con un PCB (PID, estado, registros, memoria y archivos abiertos).

10Comentario personal de los sistemas operativos

Considero que el sistema operativo es la pieza más importante de cualquier computadora, porque sin él el hardware no podría aprovecharse. Durante el curso entendí que detrás de acciones sencillas, como abrir un programa o guardar un archivo, hay procesos, hilos, administración de memoria y mecanismos de protección trabajando de forma coordinada.

Me pareció especialmente interesante el algoritmo del banquero, porque muestra cómo un problema real, el interbloqueo, puede prevenirse con lógica y planificación. También valoro la diferencia entre sistemas propietarios y de código abierto como Linux, que ha impulsado la innovación y el acceso al conocimiento.
